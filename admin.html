저장소에 올리기

바뀐 내용은 아직 이 브라우저에만 있어요. 아래 파일들을 내려받아 GitHub 저장소에 올리면 모든 사용자에게 반영돼요. (이 페이지를 새로고침하면 바뀐 내용이 사라져요)

  1. GitHub 저장소에서 sounds 폴더로 들어가 Add file → Upload files를 누릅니다.
  2. 내려받은 manifest.json과 새 오디오 파일을 끌어다 놓습니다. (같은 이름의 파일은 덮어씁니다)
  3. 사진이 있으면 sounds/images 폴더에 같은 방법으로 올립니다.
  4. 아래 Commit changes를 누르면 1~2분 뒤 앱에 반영돼요.
