# ORBIT 화이트 노이즈

집중과 수면을 위한 화이트 노이즈 웹앱이에요. PC와 휴대폰 브라우저에서 바로 쓸 수 있고, 홈 화면에 앱처럼 설치할 수도 있어요.

## 주요 기능

- 라이브러리에서 음원을 눌러 믹스에 추가하고 여러 소리를 함께 재생
- 음원마다 볼륨(고정 / 범위 랜덤 / 완전 랜덤), 재생 간격(∞ 지속 / 정해진 간격 / 범위 랜덤 / 완전 랜덤), 페이드 인·아웃 설정
- 음원 그림을 누르면 그 음원만 음소거
- 아래에서 끌어올리는 "공간 배치" 시트에서 소리 위치 조정 (이어폰 권장)
- 믹스 저장, 링크로 공유, 수면 타이머
- 내 음원 올리기 (이 기기 브라우저에만 저장돼요)
- 휴대폰에서는 좌우로 넘겨서 "나의 믹스" ↔ "라이브러리" 이동

## 기본 음원 추가하기 (관리자)

1. 배포된 주소 뒤에 `/admin.html`을 붙여 들어가요. (메뉴에는 보이지 않아요)
2. 이름, 분류, 오디오 파일, 사진(선택)을 넣고 **목록에 추가**를 눌러요.
3. 화면 아래 3번에서 새 파일들과 `manifest.json`을 내려받아요.
4. GitHub 저장소의 `sounds` 폴더에서 **Add file → Upload files**로 `manifest.json`과 오디오 파일을 올리고, 사진은 `sounds/images` 폴더에 올려요.
5. **Commit changes**를 누르면 1~2분 뒤 앱에 반영돼요.

## 지금 들어 있는 것은 임시예요

- 기본 음원 19개는 프로그램으로 합성한 임시 소리예요. 실제 녹음으로 바꾸려면 관리자 페이지에서 같은 이름의 음원을 지우고 새로 추가하거나, `sounds` 폴더의 같은 파일 이름으로 덮어쓰면 돼요.
- 카드 그림은 사진 대신 색과 무늬로 만든 임시 그림이에요. 관리자 페이지에서 사진을 넣으면 사진이 대신 보여요.
- 배경 그림 스타일은 나중에 정하기로 했어요.

## 파일 구성 (참고용)

- `index.html`, `css/`, `js/` : 앱 화면과 동작
- `sounds/manifest.json` : 기본 음원 목록, `sounds/*.mp3` : 음원 파일
- `admin.html`, `js/admin.js` : 관리자 페이지
- `sw.js`, `manifest.webmanifest`, `icons/` : 설치와 오프라인 재생
- `tools/generate_sounds.py` : 임시 음원을 만든 스크립트

앱 파일을 고친 뒤에는 `sw.js` 맨 위의 `VERSION` 값을 바꿔야 사용자에게 새 버전이 바로 보여요.
